## 🚀 엔트리(Entry) 데이터 분석 연계 방법 (선생님 & 학생 가이드)

1. **엑셀 또는 CSV 파일 다운로드**:
   - 웹 페이지에서 원하는 주제(예: `친구번호 & 색깔 데이터`)의 **[📊 엑셀(.xlsx) 받기]** 또는 **[📄 CSV 받기]**를 클릭합니다.
2. **엔트리(playentry.org) 접속**:
   - [엔트리 웹사이트](https://playentry.org) 접속 후 **[만들기]** &gt; **[작품 만들기]**로 들어갑니다.
3. **테이블 추가하기**:
   - 블록 카테고리에서 **[데이터 분석]** &gt; **[테이블 추가하기]** 클릭
   - 팝업창에서 **[파일 올리기]** 선택 후 다운로드한 파일(`친구번호_색깔_데이터.xlsx` 또는 `.csv`)을 선택합니다.
4. **차트 시각화 & 코딩 실습**:
   - 테이블 뷰에서 **[차트]** 탭을 클릭하여 **막대그래프** 또는 **원그래프**로 색깔별 선호도를 바로 시각화할 수 있습니다.
   - 블록 코딩: `[테이블]의 [색깔] 값이 [빨강]인 행의 개수` 등의 블록을 활용해 우리 반 관심사 통계 퀴즈나 추천 봇을 만들 수 있습니다.
